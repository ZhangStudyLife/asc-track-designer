# PVC 新手引导设计

## 目标

首次打开 PVC 赛道设计器时自动显示轻量、动态的聚光灯教程，帮助用户认识五项核心操作：放置赛道、自定义尺寸、中键平移、滚轮缩放，以及导入 JSON、导出图片和导出赛道 JSON。教程不得修改赛道数据，也不得改变现有鼠标、键盘、吸附或文件逻辑。

## 交互流程

教程包含五步。每步使用半透明全屏遮罩、真实界面目标高亮、简短说明卡和一个循环示意动画：

1. 高亮元件工具区，动画演示点击赛道按钮并将元件放入画布。
2. 高亮“自定义”按钮，动画演示输入长度、半径和角度。
3. 高亮画布，动画演示按住鼠标中键并向上下左右移动。
4. 高亮画布，动画演示滚轮转动及围绕鼠标位置缩放。
5. 高亮文件工具区，依次展示导入 JSON、导出图片和导出 JSON。

说明卡提供“上一步”“下一步/完成”和“跳过”。按 `Escape` 可跳过。教程期间遮罩拦截底层指针操作，避免误放置或误导出；窗口变化时重新计算目标位置。小窗口中说明卡选择目标上、下、左、右侧可用空间最大的位置，必要时限制在视口内。

## 首次启动与重播

客户端挂载后读取 `localStorage` 中的版本化 key `pvcOnboardingVersion`。值不是当前版本 `1` 时自动打开。完成或跳过均写入 `1`，以后不再自动弹出。

工具栏新增“帮助”图标按钮，点击后从第一步重新播放，但不清除首次启动记录。该 key 独立于项目、主题、尺寸和存档 key。

## 组件边界

新增 `src/features/pvc/ui/components/OnboardingTour.tsx`，负责步骤数据、目标测量、说明卡定位、键盘处理和动画标记。`PvcDesigner` 只维护是否显示教程，并在真实控件上添加稳定的 `data-tour` 属性。

动画使用 CSS transform、opacity 和简单图形，不引入动画或 UI 依赖。颜色适配当前明暗主题；在 `prefers-reduced-motion: reduce` 下停用循环位移动画，只保留静态示意。

当前已有 `exportTrackAsJSON` 函数但没有界面入口，因此文件工具区新增“导出 JSON”按钮并直接调用该函数。除此之外不新增文件能力，不增加图片底图导入。

## 验证

- 首次无 key 时自动出现，跳过或完成后刷新不再自动出现。
- 帮助按钮能随时从第一步重播。
- 五步标题、目标高亮和前后切换正确，最后一步覆盖三个文件按钮。
- 教程打开时不会新增、移动或删除赛道，也不会触发文件对话框。
- 明暗主题、桌面和窄窗口下说明卡不越界、不遮挡目标中心。
- `npm run lint`、`npm run test:run`、`npm run build` 和相关 Playwright 流程通过。
